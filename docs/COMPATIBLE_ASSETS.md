# Compatible assets (2D)

The game’s characters are **2D sprites** (PNG sheets, directional walk, etc.). Import rules are driven by **`WalkAnimation`** and `assets/sprites/` layout — not glTF/UAL.

For **new 2D art**, match existing sprite dimensions and frame grids used by `WalkAnimation` (see `scripts/systems/walk_animation.gd` and current textures under `assets/sprites/`).
